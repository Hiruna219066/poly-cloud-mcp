## 📚 How It Works

poly-cloud-mcp connects to various cloud providers through secure APIs. You will first need to set up API keys for each cloud provider you want to manage. Follow the instructions below:

1. **Obtain API Keys:**
   - For AWS, visit the IAM console to create a new user. Make sure to enable programmatic access and attach the necessary permissions.
   - For GCP, create a service account from the IAM & Admin section. Download the JSON key file.
   - For Azure, register an application in the Azure portal and obtain the client ID and secret.
   - For DigitalOcean, you can create a new personal access token in your account settings.

2. **Configure the Application:**
   - Open poly-cloud-mcp and navigate to the settings page.
   - Enter your API keys in the designated fields. 
   - Save your settings to connect the application to your cloud accounts.
